# ADR-103：新用户免费普通盲盒前端引导

## 决定

新手引导只由首次认证的权威 `welcome_reward = { kind: "free_normal_box", amount: 1 }` 触发。Web 不根据账号年龄、免费资格数量或客户端时间推断新用户；同一登录 operation 重放时，已经记录的 `completed` 或 `dismissed` 状态不得被重新置为待引导。引导只在 `normal` 账号进入可操作主界面后加载，不新增奖励领取步骤。

引导状态按项目用户 ID 保存在浏览器本地键 `evomypet.onboarding.free-normal.v1.<user_id>`，唯一有效值为 `pending`、`completed` 和 `dismissed`。首次获得权威赠礼时写入 `pending`；用户明确跳过时写入 `dismissed`；权威结果确认该资格已经消费时写入 `completed`。本地存储不可用时，本次运行期仍显示引导，但不把持久化失败伪装成业务失败，也不保存会话令牌、Telegram `initData` 或奖励数据。

待引导用户位于开盒页以外的主页面时，界面突出底部“开盒”入口并请用户主动点击。进入开盒页后，在不存在支付恢复 `resume` 参数时选中普通盲盒，突出“开 1 次”按钮，并明确本次免费且不消耗 Stars。引导层不代替用户点击、不调用 `gacha.open`、不拦截被突出按钮，也不阻止用户使用其他主页面入口；用户可以随时点击“跳过引导”。

赠礼提示与邀请交接结果由同一入场体验协调器顺序展示。引导卡已经呈现时，邀请结果显示在同一卡片内，旧的入口提示不再重复出现。Telegram 聊天写入授权请求在引导处于 `pending` 时延后，直至引导完成、跳过或引导模块加载失败，避免原生授权弹窗遮挡操作目标。

点击普通盲盒单抽后，引导进入等待状态并让既有开盒操作与结果表现完整接管画面。只有 `gacha.open` 权威响应返回 `entitlement_used = "free_normal_box"`，或刷新后的 `gacha.bootstrap.entitlements.free_normal_box` 已降为零或低于点击前计数，才记录完成；失败、取消或未消费该资格时恢复按钮引导。操作导航锁或恢复队列存在期间不展示引导层，也不提前宣告完成。

`gacha.bootstrap` 或开盒规则无法确认时，引导显示游戏化的重试与跳过入口；重试继续读取现有权威接口，不使用本地默认数据开放按钮。引导模块加载失败时退回既有赠礼提示并解除聊天授权延后，保留 `pending` 供下次进入重试。

本功能不修改身份、开盒、资格或奖励 API，不新增数据库字段、RPC、migration、分析事件或浏览器直连数据库。免费资格的创建与消费仍分别由 ADR-102 和既有 `api.gacha_open` 事务裁决。

## 验证

自动化验证覆盖权威触发、状态持久化终态、登录幂等重放和资格消费完成判定；静态门禁覆盖入口协调器、开盒按钮目标、操作结果信号、聊天授权延后、中英文文案和本文档。上线验收必须在真实 iPhone Telegram Mini App 与 Safari Web Inspector 中使用全新账号，分别验证直接入口和 Battle 入口的两段引导、主动点击、免费单抽结果、失败后恢复、跳过、再次进入不重复、邀请提示共存、网络请求和控制台状态，并核对数据库最终藏品、图鉴、任务和资格消费事实。
