# ADR-024：开盒稀有度代表与公示概率前端静态化

## 决定

开盒页的稀有度代表区不显示星标或“可能获得”区块标题，只展示前端固定公示概率大于 `0` 的稀有度。普通、稀有、史诗、传说、神话分别固定使用用户提供的编号 `1`、`2`、`3`、`4`、`5` 龙形图，从左到右沿用 `普通 → 稀有 → 史诗 → 传说 → 神话` 的唯一顺序。五张运行时文件去除粉紫背景后保存为 152×152 透明 WebP，固定存放在 `apps/web/src/shared/assets/gacha-rarity/`，由 Vite 作为 Web 版本静态资源发布；1254×1254 原图不进入仓库。最大 44×44 CSS px 外框扣除每边 `2px` 内边距和 `1px` 边框后，图片的实际方形展示区为 38×38 CSS px；152×152 精确提供小图标 4 倍屏幕像素覆盖。样式强制实际图片保持 `1:1`，不纵向拉伸、裁切主体或改变源图构图。代表图不绑定 `template_id`，不表示任何具体藏品、候选集或单模板概率。

三档页面公示概率固定写入 `apps/web/src/shared/assets/gachaRarityPresentation.ts`：普通盲盒为普通 `72%`、稀有 `25%`、史诗 `3%`；稀有盲盒为普通 `20%`、稀有 `55%`、史诗 `22%`、传说 `3%`；传说盲盒为稀有 `18%`、史诗 `55%`、传说 `24%`、神话 `3%`。开盒页不使用目录 `image_thumbnail_url`，不调用 `useCatalogQuery()`，也不读取 `gacha.bootstrap.rarity_weights` 来决定代表项、目标档次筛选或概率文案。`gacha.bootstrap` 仍只为档次、价格、资格、保底和规则完整性提供权威状态。

代表项使用无点击语义的列表展示，图片下方只显示“稀有度名称 + 固定公示总概率”。前端不提供完整候选模板列表、弹窗、单模板概率或目录权重。真实开盒仍由 `gacha.open` 和数据库按完整正式目录、当前权重、保底及事务规则裁决；静态代表图和公示概率都不参与随机、候选过滤、保底或结果决定。本裁决不修改 API、数据库定义或真实抽取规则；后续若经用户裁决改变真实概率，必须在同一上线版本同步更新本静态公示映射，禁止显示概率与实际规则不一致。
