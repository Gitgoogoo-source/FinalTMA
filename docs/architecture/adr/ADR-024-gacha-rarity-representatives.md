# ADR-024：开盒稀有度代表复用当前宠物缩略图

## 决定

开盒页的稀有度代表区不显示星标或“可能获得”区块标题，只展示当前档次基础概率大于 `0` 的稀有度。普通、稀有、史诗、传说、神话分别固定使用产品文档指定的一个 `template_id`；稀有度总概率继续读取 `gacha.bootstrap` 的当前档次 `rarity_weights`，不在前端复制概率数值，也不请求独立奖池接口。

代表图直接复用 `useCatalogQuery()` 合并快照中的 `image_thumbnail_url`；动态 pointer 切换后读取 checksum + release key 不可变目录，随模板美术原子切换。仓库和 Vercel 不再保存 `/assets/gacha/representatives/` 的五份重复 WebP；代表身份不进入资源清单的额外对象集合，也不改变 210 个母版和 420 个当前宠物运行时对象的完整性边界。

代表项使用无点击语义的列表展示，图片下方只显示“稀有度名称 + 该稀有度总概率”。前端不提供完整候选模板列表、弹窗、单模板概率或目录权重。真实开盒仍由 `gacha.open` 和数据库按完整正式目录、当前权重、保底及事务规则裁决；代表图不参与随机、候选过滤或结果决定。
