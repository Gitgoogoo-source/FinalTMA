# ADR-024：开盒稀有度代表静态资源

## 决定

开盒页“可能获得”只展示当前档次基础概率大于 `0` 的稀有度。普通、稀有、史诗、传说、神话分别固定使用产品文档指定的一张正式目录藏品图片作为代表；前端只保存代表藏品名称和版本化静态图片路径。稀有度总概率继续读取 `gacha.bootstrap` 已返回的当前档次 `rarity_weights`，不在前端复制概率数值，也不请求独立奖池接口。

五张代表图从对应的 768×768 正式母版使用 `sharp@0.35.3`、Lanczos3 缩放、WebP quality 72、alphaQuality 90、effort 6、移除元数据，确定性生成 96×96 WebP，发布在 `/assets/gacha/representatives/v1/`。该版本化路径使用一年 immutable 缓存；代表图不进入 `catalog.templates`，不改变 Catalog v1 的 420 个正式运行时文件及其锁定清单。

代表项使用无点击语义的列表展示，图片下方只显示“稀有度名称 + 该稀有度总概率”。前端不提供完整候选模板列表、弹窗、单模板概率或目录权重。真实开盒仍由 `gacha.open` 和数据库按完整正式目录、当前权重、保底及事务规则裁决；代表图不参与随机、候选过滤或结果决定。
