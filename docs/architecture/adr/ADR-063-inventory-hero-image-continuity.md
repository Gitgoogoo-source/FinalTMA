# ADR-063：藏品主图连续显示与当前页详情图预热

- 状态：已接受
- 日期：2026-08-12

## 背景

藏品页的 4×2 选择区只读取 256×256 `image_thumbnail_url`。玩家点击另一件藏品时，页面立即销毁原主图节点并首次读取该模板的 768×768 `image_detail_url`；名称、数值、按钮状态和选中框已经切换，但详情图下载与解码期间主图区域为空。真实 iPhone Telegram 与 Safari Web Inspector 复现中，公开桶详情图单次读取为 0.362 秒至 3.400 秒，3.400 秒样本在点击后 1.671 秒仍为空；相同图片已有缓存后重新选择则在 0.436 秒内显示。网络瀑布没有新的库存 API、数据库读取或图片重试，Storage 响应已经使用内容哈希地址、`public, max-age=31536000, immutable` 和 CDN 命中，因此根因是前端首次请求时机和替换策略，不是库存接口或缓存头。

## 决策

藏品主图固定同时保留当前模板的预览层与详情层。模板一经选中，预览层立即使用选择区同一个 `image_thumbnail_url`，详情层同时以 `eager`、高优先级读取 `image_detail_url`。详情图只有在当前图片节点的 `HTMLImageElement.decode()` 成功后才原位替换预览；下载中、解码中以及 1 秒和 3 秒有限重试期间始终保留正确模板的预览，不显示上一模板或空主图。全部有限重试失败后才显示随 Vercel 发布的统一宠物剪影。提交类操作的图片就绪门控继续只接受详情图解码成功，预览不伪装为详情图就绪。

每个模板的主图状态由 `template_id` 键隔离。A→B→C 快速选择会销毁较早模板的主图状态；A 或 B 的迟到下载、解码、失败与回调都不能改变 C 的预览、详情或操作就绪状态。

当前选中详情图解码成功后，藏品领域只准备玩家当前可见 4×2 页内其余模板的详情图。准备顺序固定为单并发串行，当前选中项不重复准备，浏览器优先级为 `low`；选中项位于当前页时按与选中项的格位距离由近到远准备，选中项不在当前页时按正式目录顺序只准备前 7 张并把第 8 张留给玩家主动选择。每张预热图同样必须通过公开 `pet-runtime` 详情图 URL 校验并完成 `decode()` 才记为本次 Web 运行期已准备；成功项去重，失败项不后台重试且不阻止后续玩家主动选择时沿用 `CatalogImage` 的正式有限重试。

横向滚动到另一页后，后续序列只使用新的当前页。藏品主导航页不活动或 `document.visibilityState` 不为 `visible` 时立即停止发起下一张；条件失效前已经开始的单张读取允许完成，恢复可见后才继续当前页。不得一次性准备全部 210 张详情图，不得并发抢占当前主图、首屏或其他页面资源。

本裁决不改变 API、OpenAPI、目录结构、数据库、migration、Storage 对象、缓存头或发布流程。浏览器仍只读取 API 返回的 Supabase Storage 公开桶完整图片 URL；全局 `CatalogImage` 的 URL 白名单、解码就绪、1 秒/3 秒重试与剪影语义保持不变，开盒结果的整批解码门控保持不变。

## 不变量

- 藏品名称、数值、选中框与按钮业务状态仍在点击后立即切换，主图在任何时刻只属于当前模板。
- 256px 预览只承担连续显示，不改变 768px 详情图的操作就绪标准。
- 当前页预热最多覆盖另外 7 张详情图，网络并发固定为 1，隐藏或离开藏品页后不启动新图片读取。
- 预热只优化不可变公开图片，不读取业务 API、不写状态、不改变数据库最终事实。
- 开盒单抽与十连继续等待本次全部结果图解码成功后整体显现，不复用藏品页的预览替换规则。

## 验收

静态影响域必须通过 Prettier、ESLint、Web TypeScript、架构检查和生产构建，发布前执行全量 `validate:static`。静态通过不能代替真实 Telegram 验收。

同一部署 SHA 在真实 iPhone Telegram 与 Safari Web Inspector 中以冷缓存连续选择当前页多件藏品，名称、数值、选中框和正确模板预览必须同帧切换，详情图下载及解码期间不得出现空主图或上一模板；详情图解码后只能原位替换一次。A→B→C 快速选择时，A/B 的迟到结果不得覆盖 C。当前详情图就绪后，网络瀑布只能串行出现当前可见页其他详情图且同时进行数不超过 1；横向换页后只继续新页，离开藏品页或隐藏文档后除已开始的一张外不得新增藏品详情图请求。预热失败不得自动重试；随后主动选择该模板仍按首次、1 秒、3 秒读取，最终失败时显示统一剪影且没有服务器、Supabase、请求或资源故障文案。开盒图片同步场景必须保持原验收结果。
