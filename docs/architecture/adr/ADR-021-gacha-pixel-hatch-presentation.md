# ADR-021：开盒像素破壳动画与结果展示门控

## 决定

开盒进行态由 `OperationRegistryProvider` 统一渲染独立的 DOM/SVG 像素场景，不使用服务端返回数据生成动画帧，也不修改 `gacha.open` 请求、响应或恢复契约。场景使用一个固定轮廓和底部中心锚点，通过 `normal`、`rare`、`legendary` 三组 CSS 主题变量切换蛋、怪兽与光效；所有破壳阶段在同一个 3 秒 CSS 时间轴内完成，避免多张独立帧素材产生轮廓、比例或锚点漂移。

新提交的开盒操作在前端记录动画周期边界。请求与首轮动画同时开始；成功或失败终态只在首轮结束后的第一个周期边界开放展示。周期边界到达但 operation 仍为 `confirming`、`submitting`、`pending` 或 `unknown` 时，继续下一轮；终态在后续轮次中到达时，于该轮结束后切换到既有真实结果或失败弹窗。页面恢复到已经存在的终态 operation 时直接展示真实结果，不伪造一次新的开盒过程；恢复到未决 operation 时继续显示无结论动画和既有轮询恢复。

动画遮罩承担全屏背景交互隔离，领域操作和底部导航继续使用既有 operation 锁。动画节点不显示价格、扣款、资格、藏品、保底、成功或失败结论，不参与业务状态计算。启用系统减少动态效果时，场景固定显示破壳后的像素怪兽和蛋壳，但结果展示仍遵守同一个 3 秒周期门控。
