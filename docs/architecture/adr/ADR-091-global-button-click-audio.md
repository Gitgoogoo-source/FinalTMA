# ADR-091：全局统一按钮点击音效

- 状态：已接受
- 日期：2026-08-29

## 背景

EvoMyPet 当前只有开盒演出的专用程序化 Web Audio，页面按钮没有通用点击音效。项目中的文字按钮、图标按钮、底部导航、页签、弹窗操作和按钮式卡片均使用原生 `button`；账号语言选项在原生 `button` 上补充 `radio` 语义。逐个按钮增加播放调用会重复实现、遗漏动态模块，并把表现逻辑侵入业务处理函数。

用户提供的 `button-click-music.mp3` 是固定输入：SHA-256 为 `5230a59c6cae7c0b7937099c064de2e51289a632c44f5b4128fb4499feda25e9`，时长约 `0.209s`，`44.1kHz` 双声道 MP3。全部页面按钮固定复用该文件，不生成、替换或按领域切换其他点击声音。

## 唯一结论

应用入口在执行 Telegram 初始化的同时立即加载独立的全局按钮点击音频表现模块，使其在登录、目录和首个可操作页面准备期间完成，不进入已经接近硬上限的首屏同步 JS 闭包。协调器在捕获阶段监听浏览器可信 `click`，从事件目标向上识别原生 `button`、按钮型 `input` 以及具有 `button`、`radio` 或 `tab` 语义的可点击控件。现有文字按钮、图标按钮、底部导航、页签、弹窗按钮与按钮式卡片全部由该入口覆盖；以后新增的非原生按钮必须提供正确的按钮、页签或单选语义，不能通过逐页音效调用形成第二套入口。

程序触发的非可信点击、原生 `disabled`、`aria-disabled="true"`、`inert` 或 `hidden` 范围内的控件不播放。普通游戏画面点击、滚动、拖动、输入框、只读卡片及非按钮区域不播放。按钮音效只确认玩家执行了按钮点击，不表示业务请求、资产变更或操作结果成功，也不改变按钮既有逻辑、Telegram 触觉或领域演出音效。

音频固定使用 `35%` 元素音量，并在应用挂载时创建三个预加载播放器。每次可信点击优先取得空闲播放器；快速连点使多个播放器短暂重叠，三路均占用时循环重启下一路，从而不等待上一声结束。播放必须在原始点击事件内直接发起，以满足 Telegram iOS WebView 的用户手势限制；解码、自动播放或系统静音导致的失败只允许静默省略，不能阻塞点击、显示技术错误、重试业务动作或改变页面状态。

MP3 由 Vite 作为同源哈希静态资源发布，不引入第三方音频依赖、外部域名、API、持久化设置、数据库字段或 CSP 来源。按钮音效与 ADR-082 的开盒程序化心跳和揭晓音效相互独立；玩家点击开盒按钮时先产生本 ADR 的统一短点击声，之后既有演出继续按自身时间轴运行。

## 验证

静态影响域必须通过 Prettier、ESLint、Web TypeScript、架构检查和 Production 构建，并确认构建产物包含与源文件 SHA-256 一致的单份 MP3。

发布前使用设备取消静音、媒体音量可听的真实 iPhone Telegram Mini App，逐项点击文字按钮、图标按钮、底部导航、页签、弹窗按钮和按钮式卡片，确认均播放同一声音；快速连续点击必须持续反馈，禁用按钮、拖动、滚动、输入和普通游戏画面点击必须静默。Safari Web Inspector 同时确认音频文件同源成功加载且无 CSP、媒体解码、未处理 Promise 或运行时错误。静态检查、桌面浏览器或源代码审阅不能替代真机结论。
