# ADR-073：藏品筛选浮层堆叠与触控命中

- 状态：已接受
- 日期：2026-08-15

## 背景

藏品页的稀有度、阶段与链型筛选共用 `.inventory-filter-controls` 和 `.inventory-filter-panel`。筛选面板自身使用 `position: fixed` 与 `z-index: 80`，但其父级筛选控件和后续缩略图视口都处于同一个隔离容器内，且同为 `position: relative; z-index: 2`。缩略图视口在 DOM 中更靠后，因此形成的同级堆叠上下文绘制在整个筛选控件上下文之上；面板自身的高层级无法越过父级堆叠上下文。

真实 iPhone Telegram 中因此出现奶油白面板与缩略图叠加的半透明外观。面板选项仍存在且自身允许指针事件，但覆盖位置的最终命中元素是缩略图图片和藏品按钮，点击筛选选项会改为选择后方藏品。

## 决策

`.inventory-filter-controls` 在藏品展示隔离容器内固定使用 `z-index: 3`，高于保持 `z-index: 2` 的 `.inventory-thumbnail-viewport`。筛选面板继续保留既有的视口定位、`z-index: 80`、液态玻璃样式和关闭行为，其层级只在筛选控件建立的上层堆叠上下文内排序。

稀有度、阶段与链型继续共用同一面板节点和状态入口，不新增门户、遮罩、全局弹窗或独立筛选实现。该修复不改变筛选条件、交集规则、结果数量、当前藏品选择、横向分页、数据读取或服务端契约。

## 不变量

- 三种筛选面板始终完整绘制在缩略图轨道及其藏品按钮之上。
- 面板覆盖范围内的触控由筛选选项接收，不得命中或选择后方藏品。
- 选择任一条件后关闭面板并立即应用既有筛选；点击控件外部或按下 Escape 仍关闭面板。
- 未展开筛选时，筛选条、缩略图轨道、横向分页和藏品选择的视觉尺寸及业务行为保持不变。
- 层级调整只作用于藏品展示隔离容器，不覆盖共享顶部资产栏、底部导航或全局业务弹窗。

## 验收

影响域必须通过 Prettier、ESLint、Web TypeScript、架构检查和生产构建；发布前执行全量 `validate:static`。真实 iPhone Telegram 与 Safari Web Inspector 必须在同一部署 SHA 上分别展开稀有度、阶段与链型面板，确认面板不再与缩略图混合、点击命中筛选选项、筛选结果立即变化，并确认后方藏品不会被误选。静态构建通过不能替代真机触控验收。
