# ADR-021：开盒灵契星轨特效、结果舞台与展示门控

## 决定

开盒进行态由按意图加载的 `OperationRegistryRuntimeProvider` 统一渲染 `GachaHatchAnimation`；入口中的轻量 `OperationRegistryProvider` 只负责在重型运行时就绪前锁定并交接首次操作。弹层位于 `AppShell` 外层，使用独立的全局组件类，不依赖 `.app-shell` 后代选择器。召唤、图片失败重试和结果舞台共同挂载 `GachaAstralBackdrop`：它只由 CSS 渐变、静态星点和远端光门组成，不读取背景图片。召唤阶段在该背景上叠加 ADR-067 的 WebGL2 星轨穿越；结果阶段保留同一颜色、消失点、光门位置和空间层级，并停止相机飞行，使揭晓后的画面稳定承接结果。最终结果只读取公开 `pet-runtime` 中的真实宠物图片，效果图不参与帧合成。

玩家点击一次后，动画自动运行且不可跳过。正常路径固定为前 `3300ms` 中性穿越和后 `700ms` 结果揭晓：前段按“下方灵光点火、星轨由短变长、相机加速穿越、主灵光抵达远端光门”的顺序推进，只使用冰蓝、象牙白与淡紫；到达 `3300ms` 时，如果服务端终态和本次全部结果图片都已准备完成，运行时才把单抽唯一结果或十连最高结果的真实稀有度传入最后 `700ms`。普通、稀有、史诗、传说、神话分别使用象牙白、生命绿、紫金、赤金和黑金作为最终撞入光门的强调色，不改变结果排序、概率、随机、扣款、资格、保底、藏品或任何服务端结算。

如果到达 `3300ms` 时 operation 仍未取得终态，或者成功终态已经到达但结果图片仍未完成浏览器解码，动画冻结在不含稀有度的中性光门临界画面，不重新循环、不显示进度文案，也不推测结果。当前前台运行期查询原 operation 回正且全部图片准备完成后，才从该临界画面播放一次 `700ms` 稀有度撞入和冲击揭晓；因此正常路径为 4 秒，慢响应路径只延长临界停留。明确失败终态或结果图片最终失败同样在临界门控后执行一次不含稀有度的中性收束，再展示真实失败或图片重试舞台。

前三次中性触觉使用 Telegram `selectionChanged()`；揭晓触觉只在稀有度已经允许公开后使用 `impactOccurred()`。声音继续由 Web Audio 现场合成：中性阶段为加速风噪、上升低频和三次远端脉冲，揭晓阶段为随真实稀有度增强的撞击与高频尾音；不读取音频文件，能力缺失时静默降级。WebGL2 普通设备、四核及以下、减少动态效果和 Canvas 2D 降级的固定上限由 ADR-067 裁决。

成功结果由 `GachaResultDialog` 在静止的同一灵契星域上渲染。单抽使用当前资源批次的 `image_detail_url`；十连使用全部 10 张 `image_thumbnail_url`，复制结果后仅在展示层按稀有度降序、同稀有度按 `order` 升序，再将第 1 至第 10 名依次放入轮播位置 `5 → 6 → 4 → 7 → 3 → 8 → 2 → 9 → 1 → 10`。轮播、触觉、按钮和只读展示规则保持不变；“确定”和“去藏品查看”只处理当前内存展示，“再开一次”才创建新的开盒 operation。

默认开盒页的规则、身份摘要和当前盲盒主图全部就绪后，页面立即通过既有动态加载边界准备开盒 Runtime 与表现 chunk；程序化星域不产生额外图片请求，也不把表现代码并入首屏同步闭包。按钮的 `pointerdown`、键盘 `focus` 和真实提交继续复用同一加载 Promise，因此首次点击直接进入星空通道，不显示浅色通用处理页。请求与首轮动画同时开始；成功终态使 `GachaResultDialog` 在动画层后方以 `aria-hidden`、`inert` 和 CSS 隐藏状态真实挂载。单抽详情图或全部十连缩略图分别以 `HTMLImageElement.decode()` 成功作为就绪事实；只有图片、临界门控和揭晓全部完成时，原图片节点才随完整结果一次性显现。

结果图片沿用 `CatalogImage` 的首次读取及 1 秒、3 秒两次有限重试，但开盒结果不显露通用宠物剪影。任一图片最终失败时，隐藏结果节点继续不可见，运行时切换到静止的同一灵契星域，只显示 `灵契跃迁`、`灵契尚未显现` 和 `再试一次`。玩家重试仅增加同一 `operation_id` 的图片 `retryEpoch`，绝不调用 `gacha.open`、operation 查询或确认端点，也不触发资产、资格、保底、库存、图鉴、任务或 NEW 写入。

遮罩承担背景交互隔离，领域操作和底部导航继续使用既有 operation 锁。动画阶段不提供点击、蓄能、跳过或其他交互入口；结果阶段只有十连结果横向轮播及既有确认按钮可交互。动画节点不显示价格、扣款、资格、盲盒主图、藏品、保底、成功或失败结论，不参与业务状态计算。
