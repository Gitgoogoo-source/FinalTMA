# ADR-021：开盒月夜灵契动画、结果舞台与展示门控

## 决定

开盒进行态由按意图加载的 `OperationRegistryRuntimeProvider` 统一渲染 `GachaHatchAnimation`；入口中的轻量 `OperationRegistryProvider` 只负责在重型运行时就绪前锁定并交接首次操作。弹层位于 `AppShell` 外层，使用独立的 `gacha-moon-*` 全局组件类与全屏月夜庭院背景，不依赖 `.app-shell` 后代选择器。场景以闭合和开启两张版本化 WebP 背景在同一个 3 秒 CSS 周期中交叉切换，不使用服务端返回数据生成动画帧，也不修改 `gacha.open` 请求、响应或当前运行期的原操作查询契约。

仪式中只显示月夜庭院、蛋形灵契晶壳、灵光、固定标题与固定底部文案。三档盲盒共用同一视觉，不渲染盲盒蛋或当前档次盲盒主图，不以颜色、藏品或临时稀有度预告结果。场景不提供点击、蓄能、跳过或其他交互入口；每轮在固定时点调用三次中性 Telegram `selectionChanged()` 反馈，能力缺失或客户端抛错时静默降级。

成功结果由 `GachaResultDialog` 在开启后的同一月夜庭院背景上渲染。单抽使用当前资源批次的 `image_detail_url` 居中展示一个透明背景藏品主图；十连使用全部 10 张 `image_thumbnail_url`，复制 `result.results` 后仅在展示层按稀有度降序、同稀有度按 `order` 升序，再将排序后第 1 至第 10 名依次放入轮播位置 `5 → 6 → 4 → 7 → 3 → 8 → 2 → 9 → 1 → 10`。不循环横向轮播使用透明滚动轨道和 CSS Scroll Snap 承接手势、键盘切换与吸附；十个藏品同时绝对定位在一个舞台内，依据当前中央位置连续计算水平偏移、缩放、不透明度和层级。中央选中索引变更时调用一次 Telegram `HapticFeedback.selectionChanged()`，初始居中不触发；能力缺失或客户端抛错时静默降级。每项仅渲染稀有度文字、NEW 和主图；展示排序不回写 result，不发送结果确认请求，也不改变 NEW 写入或后端结算。“确定”和“去藏品查看”只处理当前内存展示，“再开一次”才创建新的开盒 operation。

新提交的开盒操作在前端以 `operation_id` 独立记录动画档次、周期边界、结果图片状态和图片重试轮次，不使用临时 request input 或图片状态作为业务裁决。请求与首轮动画同时开始；明确失败终态只在首轮结束后的第一个周期边界开放展示。成功终态使 `GachaResultDialog` 在仪式层后方以 `aria-hidden`、`inert` 和 CSS 隐藏状态真实挂载，实际结果图片节点立即请求当前公开桶 URL；单抽的一张详情图或十连的全部十张缩略图分别调用 `HTMLImageElement.decode()`，只有全部 Promise 成功且首轮周期门控已经满足时，才在不重建这些图片节点的前提下移除隐藏状态并整体显现结果。资源提示、`load` 事件和 `decoding="async"` 属性都不是就绪事实。周期边界到达但 operation 仍为 `confirming`、`submitting`、`pending` 或 `unknown` 时继续下一轮；成功终态已到达但图片仍在准备时继续保留仪式，图片一旦全部解码即开放真实结果。同一前台运行期查询原 operation 回正时不得清除本地周期或图片门控。页面隐藏、Telegram `deactivated`、`pagehide`、刷新、WebView 重载或重新认证立即清除该 operation 的动画、图片准备和结果展示；再次进入只显示开盒首页和最新权威状态，不恢复终态或未决召唤舞台。

结果图片沿用 `CatalogImage` 的首次读取及 1 秒、3 秒两次有限重试，但开盒结果不显露通用宠物剪影。任一图片最终失败时，隐藏的结果节点继续不可见，运行时切换到使用开启背景的静态 `GachaImageUnavailable` 舞台，只显示 `月下灵契`、`灵契尚未显现` 和 `再试一次`。玩家重试仅增加同一 `operation_id` 的图片 `retryEpoch` 并重建本轮图片节点，绝不调用 `gacha.open`、operation 查询或确认端点，也不触发资产、资格、保底、库存、图鉴、任务或 NEW 写入。重试中保持静态失败舞台并禁用按钮；全部图片解码成功后显现既有权威结果，再次最终失败则恢复同一重试入口。

动画与成功结果舞台共用同一开启后的背景资源；遮罩承担背景交互隔离，领域操作和底部导航继续使用既有 operation 锁。动画阶段不提供交互入口；结果阶段只有十连结果横向轮播及既有确认按钮可交互。动画节点不显示价格、扣款、资格、盲盒主图、藏品、稀有度、保底、成功或失败结论，不参与业务状态计算。启用系统减少动态效果时，场景固定显示开启后的月夜灵契舞台，不展示盲盒主图；轮播滚动、位置吸附和按钮仍可使用，结果展示仍遵守同一个 3 秒周期门控。
