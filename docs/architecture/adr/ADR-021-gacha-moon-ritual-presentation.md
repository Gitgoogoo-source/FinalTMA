# ADR-021：开盒连续召唤演出、结果汇总与展示门控

## 决定

开盒进行态由 `OperationRegistryProvider` 在 `AppShell` 外层统一渲染 `GachaHatchAnimation`。弹层使用独立的 `gacha-moon-*` 全局组件类和全屏月夜庭院背景，不依赖 `.app-shell` 后代选择器。用户点击单抽、十连或“再开一次”时，前端在同一用户手势内尝试激活开盒专用 Web Audio，并立即渲染约 `1.45` 秒的无结论开场，同时提交唯一 `gacha.open`。三档盲盒共用同一庭院、闭合晶壳、开启晶壳、雾、粒子和色系；开场不使用服务端结果生成临时帧，不展示盲盒主图、临时藏品、临时稀有度或业务结论。

开场结束时 operation 仍为 `confirming`、`submitting`、`pending` 或 `unknown`，画面固定停留在开启后的庭院舞台，当前前台运行期继续只查询原 `operation_id`。首次取得 Schema 校验通过的成功结果后，组件复制 `result.results` 并只按服务端 `order` 升序建立展示序列；不得按稀有度排序、把高稀有度移到最后或改写原响应。每件藏品依次在中央放大进入，显示真实稀有度、透明背景主图与 NEW，停留后以增亮、缩小和光点效果退场，再进入下一件。普通、稀有、史诗、传说、神话使用逐级增加的停留权重、颜色光晕、原创合成音色和轻微 Telegram 触觉反馈，但这些差异只表现已确认结果，不参与随机、资产、资格、保底、图鉴、任务或成功判断。

十连逐件揭晓的总预算固定约 `4.45` 秒，按十件真实稀有度权重归一分配；连同开场与汇总入场后，在服务端结果及时返回时整段约 `7` 秒。单抽按唯一结果的稀有度分配约 `1.3–1.8` 秒揭晓，连同开场与汇总入场后整段约 `4` 秒。服务端结果晚于开场时，总时长随真实等待增加，不使用临时结果填充目标时长。明确失败在开场结束后进入原失败弹窗，不播放成功揭晓。

演出右上角固定提供“跳过”。成功结果已经取得时，点击后立即结束剩余逐件揭晓并进入最终汇总；结果尚未取得时，只在当前组件内记录跳过意图、把按钮文案变为“即将揭晓”，首次取得真实成功结果后直接进入汇总。跳过不创建请求、不查询另一笔 operation、不改变结果顺序，也不提前生成卡面。系统启用 `prefers-reduced-motion` 时，约 `0.28` 秒展示开启后的静态庭院，关闭背景切换、粒子、逐件放大、光点退场和汇总入场动画，真实结果取得后直接显示汇总。

成功汇总继续由 `GachaResultDialog` 使用开启后的月夜庭院渲染。单抽保持原居中藏品布局；十连保持原不循环横向缩放轮播、透明滚动轨道、CSS Scroll Snap、键盘切换与吸附，但第 1 抽至第 10 抽严格按服务端 `order` 排列，首次仍将第 5 个位置居中。汇总标题、十件藏品和按钮按固定顺序入场，当前藏品使用真实稀有度颜色光效。中央索引变更继续调用一次 Telegram `selectionChanged()`；不支持时静默跳过。每项仍只显示稀有度、NEW 和主图，不显示名称、阶段、数量、价格、实际消耗、资格、保底、操作号或后端信息。

音效由开盒专用 Web Audio 在本地合成开场、逐件揭晓、稀有强化和汇总音色，不下载或复制第三方游戏音频。只在用户点击开盒或“再开一次”时尝试恢复音频上下文；设备静音、浏览器拒绝、上下文未运行、Telegram 能力缺失或客户端抛错时静默降级，不显示设备、音频、服务器或请求提示。页面隐藏、Telegram `deactivated`、`pagehide` 或组件卸载时立即停止尚未结束的开盒音源。

新提交的开盒 operation 继续以 `operation_id`、session generation 和当前运行期内存隔离动画及结果展示。成功汇总打开后才播放汇总成功音效和触觉；`OperationRegistryProvider` 不在 HTTP 终态到达时提前播放通用成功或失败触觉，以免泄露演出节奏。遮罩继续隔离背景交互，领域按钮和底部导航沿用既有 operation 锁。“确定”和“去藏品查看”只清除当前内存展示，“再开一次”才创建新的 `gacha.open`。

页面隐藏、Telegram `deactivated`、`pagehide`、刷新、WebView 重载、重新认证或 Mini App 重启立即清除该 operation 的动画、跳过意图、音源和结果展示；再次进入只显示开盒首页并读取最新权威状态，不从全局可恢复 operation 重新弹出旧结果。当前前台运行期因网络未知而查询原 operation 并首次取得成功结果时，仍进入本 ADR 的连续揭晓流程，除非用户已经点击跳过或启用减少动态效果。
