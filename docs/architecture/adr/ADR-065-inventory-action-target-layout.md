# ADR-065：藏品操作聚焦层与三等宽布局

- 状态：已接受
- 日期：2026-08-13

## 背景

藏品页产品契约要求“进化、分解、出售”为同排三等宽操作栏。任务中心为了跳转后定位进化或分解入口，在三个操作外增加了 `.inventory-action-target` 聚焦层；藏品操作栏的 CSS Grid 因而把三列分配给聚焦层，而不是直接分配给按钮。

后续视觉改版只为 `.evolution-action > .button` 设置了 `width: 100%`。进化按钮能够铺满自己的网格列，分解与出售按钮仍保持通用 `.button` 的内容宽度，因此在真实 iPhone Telegram 中缩成只包住两个汉字的小圆按钮。三个业务动作、可用状态和服务端数据均正常，缺陷只来自聚焦层与视觉布局之间缺少尺寸契约。

## 决策

保留 `.inventory-action-target` DOM 元素及其 `tabIndex`，继续承担任务跳转后的聚焦和滚动定位，不使用 `display: contents` 取消其布局盒。

每个聚焦层固定 `min-width: 0`、`height: 100%` 并建立单项 Grid；它的直接按钮或 `.evolution-action` 固定以 `width: 100%`、`min-width: 0`、`height: 100%` 填满所在的三等分网格列。操作栏继续只由父级 `.inventory-action-grid` 定义三列、间距和行高，领域组件不各自决定按钮宽度。

该决策只修复藏品页布局，不改变进化、分解、出售的可用条件、确认流程、业务请求、库存裁决、导航或任务聚焦行为。

## 不变量

- `.inventory-action-grid` 始终只有三个同宽 `.inventory-action-target` 布局项。
- 三个可见按钮分别填满自己的聚焦层，宽度和高度一致，触控高度不低于产品规定的 `44px`。
- 最终形态、图片准备、操作阻塞、聚焦与普通可用状态只改变既定按钮状态，不改变任一网格列尺寸。
- 任务跳转仍能聚焦进化或分解入口并滚动到操作栏；聚焦层不提交请求、不持有业务状态。

## 验收

静态影响域必须通过 Prettier、ESLint、Web TypeScript、架构检查和生产构建；发布前执行全量 `validate:static`。真实 iPhone Telegram 与 Safari Web Inspector 必须在同一部署 SHA 上确认三个聚焦层等宽、三个按钮填满各自聚焦层，并覆盖 1、2、3 阶、任务跳转聚焦及按钮禁用状态。静态构建通过不能替代真机布局验收。
