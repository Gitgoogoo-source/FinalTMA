# ADR-081：开盒暖金奇幻汇聚音色

## 决定

本裁决取代 [ADR-070](ADR-070-gacha-breath-synchronized-hum.md) 的连续电子低频嗡鸣音色，但保留其前 `4000ms` 现场合成、与黑洞 13 次呼吸共用时间轴、无音频文件请求和表现失败静默降级边界。前四秒固定改为神秘、克制的暖金奇幻召唤声：柔和低频只提供逐步增加的重量，空气能量流承担每次呼吸的主要强弱变化，暖金微光频段随整体蓄能逐渐变亮；不得再出现大幅低频升降、三角波毛刺、刺耳电子嗡鸣、旋律、语音、独立撞击或提前模拟结果揭晓。最后 `700ms` 随真实稀有度变化的金光撞击与高频尾音保持原样。

全部 13 段继续使用 ADR-067 的周期 `800 / 580 / 460 / 380 / 330 / 290 / 260 / 230 / 200 / 170 / 130 / 100 / 70ms`。每轮膨胀时空气流响度和滤波频率平滑上升、收缩时平滑回落；低频底层只作窄幅变化，避免用明显音高摆动表达呼吸；暖金微光随整体成长增强但不得盖过最后揭晓声。两条正弦振荡器分别构成柔和低频底层和纯净光环，单份确定性有色噪声纹理同时经过空气流和暖金微光两个带通滤波支路，最后进入统一增益与动态压缩。前四秒不得使用三角波、锯齿波、外部音频文件、第三方音频运行时或网络请求。

表现模块空闲准备时，仍以 `2001` 个时间点生成低频频率与增益、光环频率与增益、空气流滤波频率与增益、暖金微光滤波频率与增益共八条 `AudioParam` 自动化曲线，每个空闲回调最多计算 `256` 点；同时以固定种子分块生成一份 `16384` 采样、`12000Hz` 的可循环有色噪声纹理，每个空闲回调最多计算 `2048` 个采样。该纹理不是四秒成品音频，不包含旋律、结果或盲盒档次，只作为两个滤波支路共同读取的现场合成激励源。玩家点击时若准备尚未完成，必须在可见动画开始前完成剩余曲线与纹理，并在已解锁的 `AudioContext` 内创建可复用 `AudioBuffer`；舞台发布 `data-astral-stage="ready"` 的同一回调只创建两条振荡器、一条循环纹理源、两个带通滤波支路、增益和压缩节点并应用完整曲线。

四核及以下设备不得因为渲染质量档而关闭汇聚声或揭晓声；其演出期 Telegram `HapticFeedback` 仍保持关闭。音频能力不存在、浏览器明确拒绝解锁或系统输出静音时，只允许静默省略声音，不得延迟动画、重复业务请求或改变结果。此次裁决不改变黑洞尺寸、呼吸周期、动画时长、触觉节点、结果图片门控、揭晓音效、结果展示、随机、扣款、资格、保底、藏品或任何服务端结算。

真实验收必须在设备取消静音、音量可听且 Safari Web Inspector 关闭时，使用真实 iPhone Telegram 连续执行首次开盒和“再开一次”。人耳必须确认前四秒具有柔和低频、空气汇聚和逐步变亮的暖金质感，13 次膨胀与收缩均可感知且后段加速不形成刺耳蜂鸣，前四秒没有撞击或提前揭晓，最后 `700ms` 原揭晓声保持不变。另开一轮 Inspector 确认 `AudioContext` 运行、前四秒创建两条振荡器和一条纹理源、没有音频网络请求、时间轴仍为原 13 段且业务请求没有增加。静态检查、构建、音频节点存在或普通浏览器试听不能替代真实 Telegram 的主观听感结论。

## 后果

- 玩家听到的是克制的奇幻召唤和空气能量聚拢，不再是低频电子振荡器反复升降形成的嗡鸣。
- 呼吸同步仍由与画面共用的确定时间轴裁决，不依赖生成式音频对毫秒节拍的近似理解。
- 项目不新增音频资源下载、第三方运行时或玩家会话中的生成调用；新增的短噪声纹理只在本地分块准备并由 Web Audio 现场塑形。
- 最后揭晓声和全部业务可信边界保持不变，主观音质仍必须由真实 iPhone Telegram 人耳验收。
