# ADR-012：进化顶层全屏确认页

## 决定

进化确认使用 React Portal 直接挂载到 `document.body`，并以高于顶部资产栏、藏品列表、底部导航和普通页面弹窗的固定层级覆盖主应用稳定视口。确认页从 Telegram 内容顶部安全区开始布局，到设备底部安全区结束；全局顶部资产栏、藏品页和底部导航全部保留在确认页下方且不可交互。

确认页由固定标题区、独立滚动的进化内容区和固定操作区组成。取消与确认按钮始终位于设备底部安全区上方。确认页打开时同时锁定 `html` 与 `body` 滚动，关闭时恢复打开前的滚动设置；`Escape` 只执行取消，不提交进化。

该界面只消费服务端进化预览并提交用户选择的材料数量，不缓存或裁决可用数量、Fgems、成功率、保底、扣除和目标藏品。最终结果继续由现有 `inventory.evolve` 操作、数据库事务与进化恢复工作流裁决。
