# ADR-019：Telegram 全屏内容安全区回退

## 状态

已接受。

## 背景

[Telegram Mini Apps 官方协议](https://core.telegram.org/bots/webapps)定义 `safeAreaInset` 表示设备系统安全区，`contentSafeAreaInset` 表示不会被 Telegram 原生控件覆盖的内容安全区。五个主页的头像、资产入口和页内返回按钮必须位于这两类区域之后。

2026-08-01 的 Telegram iOS 真机画面确认：Mini App 已进入原生全屏，左侧关闭控件仍覆盖在 WebView 内容首行，而客户端回报值未把资产栏推离该区域。真机截图中原生控件占用约 35 CSS px，因此全局壳层需要同时保留触控间距。

## 裁决

全局壳层的顶部起点固定使用设备安全区、Telegram 内容安全区和全屏控件回退值的最大值。官方客户端回报值始终优先；仅当 `isFullscreen = true` 且安全区顶部最大值小于 44 CSS px 时，平台同步层才将全屏控件回退值设为 44 CSS px。安全区事件返回更大真实值时使用真实值，退出全屏时回退值立即变为零。

回退值只在 `platform/telegram` 与全局壳层中维护。交易、游戏、开盒、藏品和任务页不得增加独立偏移；头像、资产栏、页面内容起点和页内返回按钮共用同一计算结果。

## 结果

五个主页保留原有组件、视觉风格、导航、状态和业务行为。原生全屏控件与全局资产栏不再共用同一垂直区域；官方客户端给出更大安全值时，布局继续自动扩展。
