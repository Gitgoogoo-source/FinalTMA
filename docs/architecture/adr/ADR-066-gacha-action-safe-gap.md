# ADR-066：开盒动作行与底部导航可见间距

- 状态：已接受
- 日期：2026-08-13

## 背景

开盒页在真实 iPhone Telegram 稳定视口中，将高 `54px` 的单抽、十连动作行放在详情区下方 `16px`。动作行底边因此越过主内容滚动区域底边 `10px`，并与固定底部导航的顶部起点重合。两个按钮各自向下延伸的外投影在滚动区域裁切边界处连成一条横向暗带，视觉上表现为底部导航仍有一层边框压住开盒按钮。

底部导航容器已经是透明、无边框、无阴影和无背景模糊；残留横带不来自导航容器，而来自开盒动作行的几何与按钮外投影。

## 决策

开盒详情区与动作行之间的固定间距由 `16px` 改为 `6px`。动作按钮继续保持 `54px` 高度、既有宽度、圆角、边框、颜色和文字层级，动作行底边固定收进主内容滚动区域，并与固定底部导航顶部保留 `10px` 可见间距。

单抽和十连按钮统一只保留顶部内高光，不绘制向下延伸的外投影；按下状态同样不得恢复外投影。该决定不改变共享底部导航的位置、尺寸、触控区域或选中态，也不改变开盒价格、免费资格、保底、提交、锁定、动画、结果或服务端裁决。

## 不变量

- 单抽和十连按钮本体始终完整可见，不被主内容滚动区域或固定底部导航裁切。
- 动作按钮高度保持 `54px`，按钮本体与底部导航之间保持 `10px` 可见间距。
- 动作按钮保留自身边框、圆角和顶部内高光，普通、禁用与按下状态均不绘制向下外投影。
- 五个主页继续共用同一个透明底部导航；开盒页不得创建页面级导航背景或调整共享导航几何。

## 验收

静态影响域必须通过 Prettier、ESLint、Web TypeScript、架构检查和生产构建。真实 iPhone Telegram 与 Safari Web Inspector 必须在同一部署 SHA 上确认：开盒动作行底边位于主内容滚动区域内，两个按钮高度均为 `54px`，按钮与底部导航之间为 `10px`，按钮计算样式没有向下外投影，导航容器仍为透明、无边框、无阴影和无背景模糊。逐页切换交易、游戏、开盒、藏品、任务，确认共享导航没有页面级背景回归；静态构建不能替代真机验收。
