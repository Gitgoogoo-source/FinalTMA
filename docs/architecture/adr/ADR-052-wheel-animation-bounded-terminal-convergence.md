# ADR-052：转盘有界终态与结果层视口锚定

- 状态：已接受
- 日期：2026-08-10

## 背景

真实 iPhone Telegram WebView 中，`wheel.spin` 已经返回成功终态，资产、今日次数和数据库账本也已经完成权威结算，但停盘动画的 `Animation.finished` 没有结束等待。领域页面把该表现层 Promise 作为打开结果弹窗前的无界闸门，因此页面持续显示“转动中...”，`wheel.spin` 操作记录继续锁定转盘按钮和底部导航。重新进入应用会按既有生命周期清除临时动画和终态展示资格，权威业务状态仍然正确。

第一版修复把 `Animation.finished` 与独立计时器放入 `Promise.race`。同一生产构建的真实 iPhone Telegram 回归证明该组合仍未恢复异步链：转盘正常旋转并准确停到服务端确认格，顶部资产和今日次数也已回正，但结果弹窗、按钮和底部导航仍未进入终态。生产包检查确认该竞速代码已经实际加载，因此最终方案不得再把原生动画完成 Promise 放进任何终态等待表达式。

第二版修复完全移除 `Animation.finished` 后，同一生产构建的真实 iPhone Telegram 回归确认转盘在固定时长后停到服务端返回的奖励，顶部资产与今日次数精确回正，中心状态已经回到“今日”，且网络中只有一笔 `wheel.spin`。结果展示模块、结果样式、礼盒图和奖励图均已在该操作后加载，但结果弹窗仍不可见，领域按钮继续被已成功 operation 锁定。这证明动画异步链已经收敛，剩余故障发生在结果层的页面几何。

`OperationRegistryRuntimeProvider` 位于主 `.app-shell` 的后置兄弟位置。结果遮罩为了复用应用视觉变量也带有 `.app-shell` 类；基础样式先用 `.modal-backdrop` 声明 `position: fixed`，但文件后段较晚出现的 `.app-shell` 又声明 `position: relative`、`height: 100dvh` 与 `overflow: hidden`。同等单类选择器按后出现者覆盖后，结果遮罩进入普通文档流并排到已经占满视口的主壳下方，而根页面自身禁止滚动，因此已挂载结果被完整裁掉。转盘专属关键帧和窄屏规则同时误放在市场表现模块中，直接进入转盘时并不会加载。

Web Animations 完成信号属于客户端表现事实，不得成为已确认业务终态能否展示的裁决条件。具体 WebKit 内部触发原因不影响前端必须有限收敛的责任。

## 决策

转盘继续先播放不带结果的连续动画，`wheel.spin` 返回并完成既有 refresh scope 后，再以服务端有序奖励中的最后一项计算唯一停盘位置。普通停盘动画固定为 2200 毫秒，减少动态效果固定为 560 毫秒；领域页面只等待同一固定时长的独立页面计时器，不读取、不捕获也不竞速 `Animation.finished`。时长到达后必须进入同一终态收敛。

收敛逻辑必须在 `finally` 中执行，并以当前 Animation 对象身份校验防止旧动画或迟到计时器覆盖新状态。仍拥有当前动画时，页面把服务端奖励对应的最终角度写入元素和内存 rotation ref，随后取消并清空 Animation。Web Animations 创建失败时立即落到最终角度；动画在视觉上提前结束、完成信号拒绝或永久不结束时均不影响独立计时器，并在固定时长后继续打开既有 `wheel.spin` 结果弹窗。

所有同时带有 `.app-shell` 与 `.operation-dialog-backdrop` 的操作结果遮罩必须在共享基础样式中重新声明视口级固定几何：`position: fixed`、`inset: 0`、非主壳宽高、零外边距和零最小高度。该双类规则的优先级必须高于后续普通 `.app-shell` 布局，确保按意图加载的 Runtime 作为主壳后置兄弟时仍覆盖当前 WebView，而不会进入普通文档流。转盘结果关键帧及其窄宽、低高度适配只归属转盘表现模块，不依赖市场表现模块被访问或缓存。

组件卸载、session generation 清理、Telegram `deactivated`、文档隐藏或 `pagehide` 触发既有 wheel presentation epoch 变化时，当前 Animation 立即取消；旧运行期的异步链在 mounted 与 epoch 校验处终止，不得恢复动画、打开旧结果或重新锁定界面。

结果弹窗打开期间继续保留原 operation 记录、领域按钮锁和底部导航锁。用户点击“确定”后只移除当前 Web 内存 operation 与结果展示，不发送 API、RPC、原操作查询或权威刷新。该决定不改变转盘概率、费用、奖励、里程碑、每日次数、幂等键、refresh scope、数据库事务或恢复语义。

## 不变量

- 服务端持久结果和数据库仍是资产、奖励、次数、里程碑与资格的唯一事实来源。
- 停盘位置只由当前 `wheel.spin` 成功结果中排序后的最后一项奖励决定，不由动画时长、客户端随机数或临时状态决定。
- 动画异常只允许缩短表现等待，不得提前宣告成功、重新提交操作、生成第二个幂等键或绕过结果弹窗。
- 已挂载的操作结果遮罩必须固定锚定当前 WebView；不得受主壳的相对定位、固定高度、裁剪或按意图模块加载顺序影响。
- `wheel.spin` 从提交到结果弹窗处理完成持续锁定本领域按钮和底部导航；不得为了消除卡死提前移除 operation。
- 不新增 API、RPC、数据库字段、migration、浏览器持久化、网络请求或监控告警。

## 验收

影响域必须通过格式、ESLint、Web TypeScript、架构检查、生产构建和全量静态门禁，首屏闭包、按意图动态加载与选择性订阅边界保持不变。

同一部署 SHA 的真实 Telegram iOS 必须分别完成单转和十连：每次只提交一个 `wheel.spin`，权威刷新完成后正常动画按既定时长停到最终奖励；即使完成信号不收敛，普通模式最迟在 2500 毫秒、减少动态效果最迟在 860 毫秒进入同一最终角度和结果弹窗。构建产物不得引用 `Animation.finished` 作为转盘终态等待。弹窗出现前后操作锁无闪断，点击“确定”不产生网络请求，随后按钮和底部导航恢复。

同一真实回归还必须在结果出现时检查遮罩的计算样式为视口级 `position: fixed` 且四边归零，弹窗位于可见 WebView 内；直接进入任务页不得依赖市场页面或市场表现资源，转盘结果关键帧与窄屏规则必须随转盘表现样式一同加载。结果模块和图片已加载但弹窗不可见、弹窗位于主壳下方或 operation 长期保持结果锁，均判定失败。

动画期间隐藏、`deactivated`、`pagehide`、刷新、关闭或重新进入必须清除旧表现资格；返回后只显示最新权威状态，不恢复旧结果、不重复提交。Safari Web Inspector 必须确认无新增脚本错误，网络、operation、资产、次数和数据库终态一致。Android 在发布前按相同部署 SHA 完成同一影响域回归；普通浏览器或静态结果不能替代真实 Telegram 验收。
