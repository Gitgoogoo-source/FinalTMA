# ADR-020：Battle 首页轻量像素对战装饰

## 状态

已接受。

## 背景

Battle 首页顶部主视觉需要改为两只像素怪兽自动对战，并保持 Telegram 移动端卡片紧凑、项目暖色调一致和极小传输体积。该画面只是前端装饰，不得表示真实出招、伤害或胜负，也不得引入新的后端状态。

## 裁决

两只怪兽使用 React 内联 SVG 的少量整数坐标矩形与多边形组成，通过 `shape-rendering="crispEdges"` 保持像素边缘。进攻位移、命中闪光和投射物只使用已有 Battle CSS 内的 3 秒循环关键帧。实现不新增位图、精灵图、音频、第三方动画依赖、Canvas 运行时、网络请求或战斗数据订阅。

主视觉不声明交互语义，像素场景对辅助技术隐藏；用户启用 `prefers-reduced-motion` 时停止循环和闪烁，保留静态双怪兽画面。

## 结果

Battle 首页顶部只显示 `1v1 BATTLE`、“胜者拿走奖池”和紧凑的像素对战画面。三档入场费、队伍选择、真实战斗、资产、权限、幂等、错误处理和数据一致性链路全部保持不变。
