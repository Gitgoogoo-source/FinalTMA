# ADR-085：Gems 对外名称与内部 FGEMS 标识隔离

- 状态：已接受
- 日期：2026-08-24

## 背景

游戏内绿色切面宝石资源此前使用旧品牌名，现统一改名为 `Gems`。本次变更只改变资源的对外名称，不改变余额、奖励、消耗、锁定、账本、支付、恢复或任何结算规则。

项目已经在数据库币种枚举、RPC、API JSON、TypeScript 属性、操作名称、CSS 类名和资源文件名中使用 `FGEMS` 或 `fgems` 作为稳定内部标识。把这些标识一并改名不会产生新的玩家结果，却会破坏既有数据库与跨层契约，因此必须将玩家名称与实现标识明确隔离。

## 决策

所有简体中文与英文玩家界面、无障碍名称、操作进度与结果、服务端业务提示、分享文案，以及项目中供人阅读的产品、架构、验收和设计说明，统一使用首字母大写的品牌名 `Gems`。任何玩家可见位置不得继续显示旧品牌名、带连字符的旧变体或其他旧写法。

数据库币种代码 `FGEMS`，API/RPC 字段与结果键中的 `fgems`，既有表字段、函数、operation use case、TypeScript 属性、CSS 选择器、图片路径和文件名继续作为稳定内部标识。本次变更不创建兼容字段、不迁移数据库标识、不改变请求或响应 Schema，也不修改资源数值。

本 ADR 取代现行文档中使用旧品牌名或声明旧名称保持不变的内容。代码和数据库中的 `FGEMS` / `fgems` 只能作为内部标识理解，不得直接展示给玩家。

## 不变量

- Gems 余额和所有业务结果继续来自既有服务端与数据库权威链路，前端不计算或裁决余额。
- 远征、转盘、分解、进化、任务、图鉴、VIP 和邀请奖励的金额、概率、上限、幂等、事务与恢复规则保持不变。
- Gems 不等于游戏资源 Stars、Telegram Stars、TON、免费盲盒资格或其他资产。
- 本次命名不新增数据库 migration，不清空或改写既有余额、账本、operation 或业务数据。
- 英文和简体中文界面均固定使用 `Gems`，不因数量为一改写成 `Gem`。

## 验证

代码搜索必须确认玩家文案和人类可读项目说明只使用 `Gems`，不再出现旧品牌名或其连字符变体；允许保留项只能是不可见的 `FGEMS` / `fgems` 内部标识。Supabase schema 与基线 migration 中的玩家业务提示必须一致。

影响域必须通过格式、ESLint、API Contracts、Web/API TypeScript、i18n、数据库一致性、架构检查和生产构建。推送后以同一 Git SHA 核对 Vercel 部署；玩家可见结果仍须在真实 Telegram Mini App 中验收，静态检查、普通浏览器或部署 READY 不能替代真机结论。
